# StaffControl - Система интеллектуального управления проектными кадрами

## 📌 О проекте

Информационная система «StaffControl» предназначена для автоматизации управления проектными кадрами и расчёта заработной платы в IT-компаниях.

**Основной функционал:**
- 👥 Управление сотрудниками (CRUD)
- 📁 Управление проектами (CRUD)
- 💰 Расчёт заработной платы по формуле: `Ставка × Часы × Коэффициент роли`
- 📊 Контроль бюджета проектов
- 🔐 Разграничение доступа по ролям (ADMIN, HR, MANAGER, EMPLOYEE)
- 📋 Назначение сотрудников на проекты с выбором роли
